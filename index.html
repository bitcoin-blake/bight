Bight, Reef, Winch and Hitch share this site's storage, so one copy of the node's files serves all four, and one tab runs the node. Source: github.com/bitcoin-blake/bight.
Welcome to Bight

To show the mempool, this tab runs a node: it downloads the chain's state at block 150,307 (870 MB), checks it, and validates every block since. That takes a few minutes on a fast connection and longer on a slow one; it is kept for next time (and shared with Reef, Winch and Hitch), and resumes if interrupted. Avoid starting on a metered connection.
